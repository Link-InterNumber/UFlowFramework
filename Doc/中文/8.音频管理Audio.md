# 音频管理工具文档

## 🎵 **工具特点**

1. **树状管线结构设计**
    - 音频管理工具采用树状结构设计，便于管理和扩展不同类型的音频。
    - 使用消息路由机制，实现音频播放请求的分发和处理。

2. **对象池优化**
    - 使用对象池管理音频源（`AudioSource`），减少频繁创建和销毁音频对象带来的性能开销。

3. **灵活的音频控制**
    - 支持音量调节、静音、淡入淡出、暂停、切换音频组等功能。
    - 支持3D音效的空间化处理（`spatialBlend`）。
    - 支持不同管线应用不同混音器组（`AudioMixerGroup`）的设置。

4. **异步加载支持**
    - 音频资源通过异步加载方式获取，避免阻塞主线程。
    - 使用音频文件路径进行自动加载，支持动态加载和卸载音频资源。

5. **事件触发播放**
    - 提供触发器组件（`AudioTrigger`）和设置器组件（`AudioSetter`），可通过物理碰撞或UI事件触发音频播放。

6. **可扩展性**
    - 使用接口（如`IAudioPipelineBehavior`）设计，便于扩展和自定义音频播放逻辑。

7. **以组为单位的背景音乐管理**
    - 支持将背景音乐分组管理，便于统一控制和切换不同音频组。
    - 可以在保留当前音频状态的情况下，切换到新的音频组。
    - 支持在切换音频组时，淡入淡出当前音频，避免突兀的音频切换。

## 🛠️ **使用方法**

### 1. **初始化音频管理器**

音频管理器会在游戏启动时自动初始化，无需手动调用。  

```csharp
  protected override void Awake()
  {
      base.Awake();
      DontDestroyOnLoad(gameObject);
      _assetLoader = AssetUtils.SpawnLoader("AudioManager");
      BuildPipeLine();
  }
```
需要关注的是 `BuildPipeLine()` 方法，它负责构建音频管线。
默认的音频管线结构如下：
   - Master
     - Music (BGM)
     - Dialog
     - SFX
       - SFXUI
       - SFX3D
       - Ambience
     - System

其中 *Master*、*Music*、*SFX*管线没有播放行为，*Dialog*、*SFXUI*、*SFX3D*、*Ambience*、*System*管线分别使用了不同的播放行为。
工具内实现了对应类型音频的接口（`IAudioPipelineBehavior`），可以根据需要进行扩展和替换。

管线存在父子关系，操作父节点管线调整最大音量、暂停/恢复、静音的行为会传递给子节点管线。
在运行时支持动态添加/删除管线，但需要确保能从*Master*节点出发找到，否则音频请求无法通过消息路由到达目标管线。

管线构造方法
   - 创建 `AudioPipeline` 实例；
   - 调用 `AudioPipeline` 实例的 `Init` 方法，传入管线Id和播放行为实例；
   - 播放行为是一个继承 `IAudioPipelineBehavior` 接口的类，用以定义如何处理音频请求；
   - 为管线设置父节点管线


```csharp
private void BuildPipeLine()
{
   _masterPipeline = new AudioPipeline();
   _masterPipeline.Init((int)AudioSourceType.Master, null);

   var bgmPipeline = new AudioPipeline();
   bgmPipeline.Init((int)AudioSourceType.Music, null); //new CycleBGMAudioPipelineBehavior(bgmPipeline));
   bgmPipeline.parent = _masterPipeline;

   var dialogPipeline = new AudioPipeline();
   dialogPipeline.Init((int)AudioSourceType.Dialog, new CutoffAudioPipelineBehavior(dialogPipeline));
   dialogPipeline.parent = _masterPipeline;
   
   var SFXPipeline = new AudioPipeline();
   SFXPipeline.Init((int)AudioSourceType.SFX, null);
   SFXPipeline.parent = _masterPipeline;

   var SFXUiPipeline = new AudioPipeline();
   SFXUiPipeline.Init((int)AudioSourceType.SFXUI, new PoolSFXAudioPipelineBehavior(SFXUiPipeline));
   SFXUiPipeline.parent = SFXPipeline;
   _updatePipelineBehaviors.Add(SFXUiPipeline.updateBehavior);

   var SFX3DPipeline = new AudioPipeline();
   SFX3DPipeline.Init((int)AudioSourceType.SFX3D, new PoolSFXAudioPipelineBehavior(SFX3DPipeline));
   SFX3DPipeline.parent = SFXPipeline;
   _updatePipelineBehaviors.Add(SFX3DPipeline.updateBehavior);

   var ambiencePipeline = new AudioPipeline();
   ambiencePipeline.Init((int)AudioSourceType.Ambience, new SampleAudioPipelineBehavior(ambiencePipeline));
   ambiencePipeline.parent = SFXPipeline;

   var systemPipeline = new AudioPipeline();
   systemPipeline.Init((int)AudioSourceType.System, new SampleAudioPipelineBehavior(systemPipeline));
   systemPipeline.parent = _masterPipeline;
}
```

可以通过 `AddAudioMixerGroupToPipeline` 和 `RemoveAudioMixerGroupFromPipeline` 为管线添加混音器组；
通过 `GetPipelineMixerCtrl` 可以获取特定管线的混音器组控件，方便操作音频效果。

### 2. **播放音频**

#### a. **播放背景音乐（BGM）**
播放背景音乐会有组别的概念，背景音乐会根据组别进行切换。

```csharp
AudioManager.instance.PlayMusic("MusicClipPath", MusicGroup.Default, fadeoutTime: 0.5f, intervalTime: 0.3f, fadeinTime: 0.5f);
```
使用 `SwitchMusicGroup` 方法可以切换背景音乐组。使用 `DisposeMusicGroup` 方法可以释放某个背景音乐组的资源。
在调用 `PlayMusic` 时，会自动切换到给定的背景音乐组，但不会释放前一个背景音乐组的资源。

#### b. **播放环境音效（Ambience）**

```csharp
PlayAmbience(clipRef:"clipPath", isLoop:true, fadeoutTime:1f, intervalTime:1f, fadeinTime:1f)
```

#### c. **播放对话音频（Dialog）**

```csharp
AudioManager.instance.PlayDialog("DialogClipPath", () => Debug.Log("Dialog Finished"));
```

#### d. **播放3D音效（Effect3D）**

音效播放使用了队列机制，避免了音效播放时的卡顿现象。

同时限制相同音效的同时播放数量，避免了音效过多导致的音频混乱。

- **绑定到对象**：

```csharp
AudioManager.instance.RequestPlayEffect(clipRef:"EffectClipPath", onUI:false, attached:attachedGameObject, position:Vector3.zero, full3D:true)
```

- **播放在指定位置**：

```csharp
AudioManager.instance.RequestPlayEffect(clipRef:"EffectClipPath", onUI:false, attached:null, position:Vector3.zero, full3D:true)
```

#### e. **播放UI音效（UIEffect）**

```csharp
AudioManager.instance.RequestPlayEffect(clipRef:"EffectClipPath", onUI:true, attached:null, position:Vector3.zero, full3D:false)
```

### 5. **触发器与设置器**

#### a. **使用`AudioTrigger`**

- 在需要触发音效的对象上添加`AudioTrigger`组件。
- 碰撞触发时自动播放音效。

#### b. **使用`AudioSetter`**

- 在需要播放音效的UI或对象上添加`AudioSetter`组件。
- 设置音频路径和触发条件（如`playOnEnable`、`playOnUp`等）。
- 配置在`AudioSetter`上的AudioClip并不是将资产直接赋值给`AudioSetter`，而是通过记录路径来实现的。
- 这样做的好处是可以在运行时动态加载音频资源，避免了在编辑器中直接引用音频文件的限制。

#### c. **Button组件与音效**

- `ButtonAddAudioEditor`可以快速为`Button`组件添加音效触发器。
- 在`Button`的Inspector面板中，点击`Add Up AudioTrigger`按钮，可以为按钮的`PointerUp`事件添加音效触发。
- 点击`Add Down AudioTrigger`按钮，可以为按钮的`PointerDown`事件添加音效触发。
- 添加后，音效触发器会自动挂载`AudioSetter`组件，并设置对应的触发条件（如`playOnUp`或`playOnDown`）。

## ⚠️ **注意事项**

1. **音频资源路径**
    - 确保音频资源路径正确，并已加载到项目中。

2. **对象池管理**
    - 音频管理器使用对象池管理`AudioSource`，请确保对象池容量足够，避免音频播放失败。

3. **音频类型区分**
    - 不同类型的音频有独立的音量和静音设置，需分别管理。
    - 子节点管线的音量受父节点管线影响，真实音量 = 父节点设置音量 * 子节点设置音量；
    - 父节点管线暂停/恢复、静音/取消静音会同时作用与子节点管线，父节点暂停/静音优先级高于子节点。

4. **淡入淡出时间**
    - 设置淡入淡出时间时，确保时间值合理，避免音频切换过于突兀。

5. **性能优化**
    - 避免频繁创建和销毁音频对象，尽量使用对象池管理音频播放。

6. **扩展性**
    - 如果需要自定义音频播放逻辑，可实现相关接口（如`IAudioPipelineBehavior`）并替换默认实现。
