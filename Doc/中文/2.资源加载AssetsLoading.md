# 资源加载系统文档

## 🌟 系统特点

### 1.🚀 只提供异步加载

- 资源系统以异步加载为核心，避免阻塞主线程。
- 当前支持多种异步消费方式：
  - 直接传入成功 / 失败回调
  - `yield return LoaderYieldInstruction<T>`
  - 使用 `LoaderYieldInstruction<T>.OnLoadSuccess()` / `OnLoadFailed()` 注册回调
  - 在非 WebGL 平台使用 `LoadTask<T>()`

### 2.🔧 接口与工具分层

- `IAssetManager` 负责底层资源系统初始化、创建 Loader、场景加载和预加载。
- `IAssetLoader` 负责当前业务情景下的缓存、异步加载和资源释放。
- `AssetUtils` 负责统一入口、Loader 对象池、批量准备、句柄池和路径工具。
- `LoaderYieldInstruction<T>` 与 `ChainedLoadingLoader` 负责异步流程控制。

### 3.📦 离散化管理

- 资源通过实例化的 `IAssetLoader` 按情景隔离管理，例如打开一个 UI、进入一场战斗、创建一个对象池。
- 回收某个 `IAssetLoader` 只会清理该 Loader 自己的缓存，不会影响其他 Loader 的同名资源。
- `AssetLoaderPool` 在回收 Loader 时会先检查 `IsAnyLoading()`，仍有加载中的资源时会等待完成后再真正回收。

### 4.⚡ 当前支持的加载模式

- `AssetBundle`
- `Addressable`
- `Resources`

当前实现通过修改 `AssetUtils` 内部的 `_loadMode` 字段来选择模式，默认值为 `LoadMode.Addressable`。

## 🧩 当前核心接口

### IAssetManager

当前 `IAssetManager` 只保留“管理器能力”。Loader 的对象池、标签管理和回收时机由 `AssetUtils` 与 `AssetLoaderPool` 负责。

```csharp
public interface IAssetManager
{
    AssetInitState initState { get; }

    float initProcess { get; }

    void Init(MonoBehaviour coroutineRunner, Action callBack);

    IAssetLoader CreateLoader();

    void LoadScene(string sceneName, Action onComplete, bool unLoadOtherScene = false);

    void UnloadScene(string name);

    void ClearUnusedAsset();

    void PreloadAsset(string address);
}
```

### IAssetLoader

当前 `IAssetLoader` 使用框架内定义的委托，而不是旧文档中的 `Action<T>` / `Action`。

```csharp
public delegate void OnLoadSuccess<T>(T asset);
public delegate void OnLoadFailed();

public interface IAssetLoader
{
    public int index { get; }

    public bool spawned { get; }

    public string tag { get; set; }

    public void Init();

    public void Deinit();

    public bool Release(string address);

    public bool IsLoading(string address);

    public bool IsAnyLoading();

    public void LoadAsync<T>(string address, OnLoadSuccess<T> onSuccess, OnLoadFailed onFail = null)
        where T : UnityEngine.Object;

#if !UNITY_WEBGL
    public Task<T> LoadTask<T>(string address) where T : UnityEngine.Object;
#endif

    public LoaderYieldInstruction<T> LoadAsYieldInstruction<T>(string address)
        where T : UnityEngine.Object;

    public void AsyncLoadNInstantiate(string address, OnLoadSuccess<GameObject> onSuccess, OnLoadFailed onFail = null);

    public void AsyncLoadNInstantiate(string address, Transform parent, OnLoadSuccess<GameObject> onSuccess, OnLoadFailed onFail = null);

    public void LoadAllAsync<T>(string label, OnLoadSuccess<IList<T>> onSuccess, OnLoadFailed onFail = null)
        where T : UnityEngine.Object;
}
```

### LoaderYieldInstruction<T>

`LoaderYieldInstruction<T>` 仍可直接 `yield return`，但回调注册方式已经变为方法调用，而不是 `onLoadSuccess +=` 这种事件字段写法。

```csharp
public class LoaderYieldInstruction<T> : CustomYieldInstruction, ILoaderYieldInstruction
    where T : class
{
    public override bool keepWaiting => !isDone;

    public bool isDone { get; }

    public bool autoRelease { get; }

    public T asset { get; }

    public void OnLoadSuccess(OnLoadSuccess<T> callback);

    public void OnLoadFailed(OnLoadFailed callback);

    public void Dispose();
}
```

## 🧰 AssetUtils 常用入口

```csharp
public static class AssetUtils
{
    public static AssetInitState initState { get; }
    public static float initProcess { get; }
    public static LoadMode loadMode { get; }

    public static void Init(MonoBehaviour coroutineRunner, Action callBack);

    public static IAssetLoader SpawnLoader(string tag = "");
    public static void DeSpawnLoader(IAssetLoader assetLoader);
    public static void DeSpawnAllLoader();
    public static void DeSpawnLoaderByTag(string tag);

    public static void LoadScene(string sceneName, Action onComplete, bool unLoadOtherScene = false);
    public static void UnloadScene(string name);

    public static AssetBatchLoader SpawnBatchLoader(IAssetLoader loader, string[] labels, Action onComplete, bool isConcurrent = false);
    public static void DespawnBatchLoader(AssetBatchLoader handler);

    public static LoaderYieldInstruction<T> GetLoadHandler<T>(string path, bool autoRelease = false) where T : class;
    public static void ReleaseLoadHandler<T>(ILoaderYieldInstruction item) where T : class;

    public static void PreloadAsset(string address);
    public static void ClearUnusedAsset();

    public static string EditorCheckPath(string paths);
    public static string CombinePaths(params string[] paths);
    public static bool TryGetSubAssetName(string path, out string mainPath, out string subAssetName);
}
```

补充说明：

- `SpawnLoader()` / `DeSpawnLoader()` 是业务侧最常用的 Loader 生命周期入口。
- `GetLoadHandler<T>()` / `ReleaseLoadHandler<T>()` 适用于需要手动管理 `LoaderYieldInstruction<T>` 生命周期的场景。
- `CombinePaths()` 会统一将分隔符转成 `/`，更适合资源路径。
- `TryGetSubAssetName()` 可拆分 `mainPath[subAssetName]` 形式的子资源路径。

### 1. 基础加载流程

```csharp
public class ExampleBattleCase
{
    private IAssetLoader _assetsLoader;
    private Stack<GameObject> _enemyPool;

    public void Init()
    {
        _assetsLoader = AssetUtils.SpawnLoader(GetType().Name);
        AssetUtils.PreloadAsset("Assets/Res/exampleMapPath.prefab");
        LoadMap();
        LoadHero();
        CoroutineRuner.StartCoroutine(CreateEnemyPool());
    }

    public void Deinit()
    {
        ClearEnemyPool();
        AssetUtils.DeSpawnLoader(_assetsLoader);
        _assetsLoader = null;
    }

    private void LoadMap()
    {
        _assetsLoader.LoadAsync<GameObject>("Assets/Res/exampleMapPath.prefab", OnMapLoaded, OnMapLoadFailed);
    }

    private void OnMapLoaded(GameObject mapPrefab)
    {
        var map = GameObject.Instantiate(mapPrefab);
        Debug.Log($"Map created: {map.name}");
    }

    private void OnMapLoadFailed()
    {
        Debug.LogError("Map load failed.");
    }

    private void LoadHero()
    {
        var loadHandler = _assetsLoader.LoadAsYieldInstruction<GameObject>("Assets/Res/exampleHeroPath.prefab");
        loadHandler.OnLoadSuccess(prefab =>
        {
            var hero = GameObject.Instantiate(prefab);
            Debug.Log($"Hero created: {hero.name}");
        });
        loadHandler.OnLoadFailed(() =>
        {
            Debug.LogError("Hero load failed.");
        });
    }

    private IEnumerator CreateEnemyPool()
    {
        var loadHandler = _assetsLoader.LoadAsYieldInstruction<GameObject>("Assets/Res/exampleEnemyPath.prefab");
        yield return loadHandler;

        if (!loadHandler.asset)
        {
            Debug.LogError("Create enemy pool failed.");
            yield break;
        }

        _enemyPool = new Stack<GameObject>();
        for (var i = 0; i < 50; i++)
        {
            _enemyPool.Push(GameObject.Instantiate(loadHandler.asset));
        }

        AssetUtils.ReleaseLoadHandler<GameObject>(loadHandler);
        Debug.Log("Enemy pool created.");
    }

    private void ClearEnemyPool()
    {
        if (_enemyPool == null) return;
        while (_enemyPool.Count > 0)
        {
            GameObject.Destroy(_enemyPool.Pop());
        }
        _enemyPool = null;
    }
}
```

### 2. 使用 LoadTask<T>

`LoadTask<T>()` 只在非 WebGL 平台可用：

```csharp
#if !UNITY_WEBGL
private async Task<GameObject> LoadCharacterAsync(IAssetLoader loader, string address)
{
    return await loader.LoadTask<GameObject>(address);
}
#endif
```

### 3. 按标签批量准备资源

`AssetBatchLoader` 适合在进入场景前先把若干标签资源准备到指定 Loader 中：

```csharp
private IEnumerator PrepareBattleAssets(IAssetLoader loader)
{
    var labels = new[] { "battle_ui", "battle_audio", "battle_fx" };
    var batch = AssetUtils.SpawnBatchLoader(loader, labels, () =>
    {
        Debug.Log("Batch prepare complete.");
    }, isConcurrent: true);

    yield return batch.WaitForCompletion();
    Debug.Log($"Prepare progress: {batch.progress}");

    batch.Unprepare();
    AssetUtils.DespawnBatchLoader(batch);
}
```

- `progress` 取值范围为 `0~1`。
- `Unprepare()` 会释放当前批次已成功加载的标签资源。
- `DespawnBatchLoader()` 负责回收批量句柄本身。

### 4. 使用 ChainedLoadingLoader 串行加载

```csharp
private IEnumerator LoadOpeningSequence(IAssetLoader loader)
{
    var chain = new ChainedLoadingLoader(loader);

    chain.PushLoadTask<GameObject>("Assets/Res/UI/Open.prefab", prefab =>
    {
        GameObject.Instantiate(prefab);
    });

    chain.PushLoadTask<AudioClip>("Assets/Res/Audio/OpenBgm.wav", clip =>
    {
        AudioSource.PlayClipAtPoint(clip, Vector3.zero);
    });

    chain.OnComplete(() =>
    {
        Debug.Log("Chained loading complete.");
    });

    yield return chain;
    chain.Dispose();
}
```

## 📖 框架内已接入的使用场景

- UI 系统
- 对象池系统
- 音频系统

这些模块通常会在合适的生命周期中自动申请并回收 `IAssetLoader`。

```csharp
private IAssetLoader _assetsLoader;
public IAssetLoader assetsLoader => _assetsLoader;

void IUIComponent.Open(object data)
{
    if (_assetsLoader == null || !_assetsLoader.spawned)
        _assetsLoader = AssetUtils.SpawnLoader(GetType().Name);
    OnOpen(data);
}

public virtual void OnUIDestroy()
{
    AssetUtils.DeSpawnLoader(_assetsLoader);
    _assetsLoader = null;
}
```

## ⚠️ 注意事项

1. `LoadTask<T>()` 当前只在非 WebGL 平台可用，跨平台逻辑建议改用 `LoadAsYieldInstruction<T>()` 或加条件编译。
2. `LoaderYieldInstruction<T>` 的回调注册方式是 `OnLoadSuccess()` / `OnLoadFailed()`，不要再使用旧文档里的 `onLoadSuccess +=` 写法。
3. `AssetUtils.DeSpawnLoader()` 可能不会立即释放 Loader，因为对象池会等待该 Loader 的异步加载全部结束。
4. `AssetBatchLoader.Unprepare()` 负责释放当前批次已准备好的资源，`AssetUtils.DespawnBatchLoader()` 负责回收批量句柄本身，两者职责不同。
5. 资源路径建议统一使用 `AssetUtils.CombinePaths()` 或通过 `EditorCheckPath()` 校验，避免 `\` 分隔符导致路径不一致。
6. 如果使用子资源路径，请保持 `mainPath[subAssetName]` 格式，并通过 `TryGetSubAssetName()` 解析。
