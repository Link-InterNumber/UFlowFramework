# UI组件

## 1. ButtonEx

### ButtonEx 功能

`ButtonEx` 是一个扩展自 Unity `Button` 的自定义 UI 组件，提供了额外的功能，如长按检测和长按重复触发事件。它适用于需要增强交互功能的按钮场景。

1. **长按检测**：
    - 支持检测按钮的长按操作。
    - 可设置长按触发的时间阈值。

2. **长按重复触发**：
    - 支持在长按状态下以固定间隔重复触发事件。

3. **长按事件**：
    - `onLongPress`：长按触发的事件。
    - `onLongPressUp`：长按结束时触发的事件。

4. **自定义属性**：
    - `enableLongPress`：是否启用长按功能。
    - `longPressRepeat`：是否启用长按重复触发。
    - `longPressStartTime`：长按开始的时间阈值。
    - `longPressTriggerTime`：长按触发的时间阈值。
    - `longPressIntervalTime`：长按重复触发的时间间隔。

---

### 使用方法

#### 1. 添加 ButtonEx 到场景

- 在 Unity 编辑器中，右键点击层级视图，选择 `GameObject > UI > ButtonEx`，即可添加一个 `ButtonEx` 组件。

#### 2. 设置长按功能

- 在 `Inspector` 面板中，勾选 `Enable Long Press`。
- 配置以下参数：
    - `Long Press Start Time`：设置判断长按开始的时间阈值（单位：秒），按下达到这个时间后，`onClick` 事件将无法触发。
    - `Long Press Trigger Time`：设置长按触发的时间阈值（单位：秒），达到这个时间后将触发 `onLongPress` 事件。
    - `Long Press Interval Time`（可选）：设置长按重复触发的时间间隔（单位：秒），达到长按触发时间后，每隔X秒重复触发
      `onLongPress` 事件。

#### 3. 绑定事件

- 在 `Inspector` 面板中，展开 `On Long Press` 和 `On Long Press Up`，绑定需要触发的事件。

#### 4. 示例代码

```csharp
using UnityEngine;

public class ButtonExExample : MonoBehaviour
{
    public ButtonEx buttonEx;

    private void Start()
    {
        buttonEx.onLongPress.AddListener(OnLongPress);
        buttonEx.onLongPressUp.AddListener(OnLongPressUp);
    }

    private void OnLongPress()
    {
        Debug.Log("Button is being long-pressed!");
    }

    private void OnLongPressUp()
    {
        Debug.Log("Button long-press released!");
    }
}
```

### 注意事项

- 如果启用了长按功能，短按事件（如 `OnClick`）将在长按开始后被屏蔽。
- 可通过 `ButtonExEditor` 快速添加音效触发器（如按下或释放时播放音效）。

## 4. 可插拔屏幕输入检测

### 简介

`ScreenInputMinitor` 是 UFlow 提供的一个 MonoBehaviour 组件，用于统一管理和分发屏幕输入事件（如点击、拖拽、缩放、长按等）。它支持多种输入处理器的注册、注销、启用、禁用和事件监听，方便开发者在项目中灵活扩展和响应不同类型的触控操作。

### 主要功能

- 注册/注销不同类型的输入处理器（如点击、拖拽、缩放等）。
- 支持动态添加和移除输入事件监听器。
- 自动在生命周期内启用/禁用所有输入处理器。
- 提供便捷的接口判断输入处理器是否已注册，并获取实例。
- 支持 Unity 新输入系统（EnhancedTouch）。
- 内置测试方法，方便调试各类输入事件。

### 使用方法

将 `ScreenInputMinitor` 挂载到场景中的任意 GameObject 上。
可以通过泛型方法注册输入处理器。例如，注册点击处理器：

```csharp
screenInputMinitor.RegisterInputHandle<ScreenTapHandle>();
```

或者直接传入实例：

```csharp
var tapHandle = new ScreenTapHandle();
screenInputMinitor.RegisterInputHandle(tapHandle);
```

为指定类型的输入处理器添加事件监听：
```csharp
screenInputMinitor.AddListener<ScreenTapHandle>(OnTapEvent);
```

事件回调方法示例：

```csharp
void OnTapEvent(ScreenInputEvent inputEvent)
{
    Debug.Log($"Tap at: {inputEvent.screenPos}");
}
```

启用/禁用输入处理器

```csharp
screenInputMinitor.EnableInput<ScreenTapHandle>();
screenInputMinitor.DisableInput<ScreenTapHandle>();
```

注销输入处理器

```csharp
screenInputMinitor.UnregisterInputHandle<ScreenTapHandle>();
```

检查和获取处理器

```csharp
bool isRegistered = screenInputMinitor.IsInputHandleRegistered<ScreenTapHandle>();

if (screenInputMinitor.TryGetInputHandle<ScreenTapHandle>(out var handle))
{
    // 使用 handle
}
```

### 注意事项

- 输入处理器需实现 `IScreenInputHandle` 接口。
- 事件监听需使用 `ScreenInputEventHandler` 委托。
- 若启用 Unity 新输入系统，请确保 `ENABLE_INPUT_SYSTEM` 宏已定义。

**示例：注册并监听点击事件**

```csharp
// 注册点击处理器
screenInputMinitor.RegisterInputHandle<ScreenTapHandle>();

// 添加点击事件监听
screenInputMinitor.AddListener<ScreenTapHandle>(OnTapEvent);

void OnTapEvent(ScreenInputEvent inputEvent)
{
    Debug.Log($"Tap Detected: {inputEvent.screenPos}");
}
```

如需扩展更多输入类型，只需实现新的 `IScreenInputHandle` 并注册即可。
