# 资源管理工具

## 1. 批量缩放图片

**TextureBatchResizer** 是一个 Unity 编辑器工具，用于批量缩放和保存图片。你可以选择源文件夹，设置目标文件夹，指定缩放百分比，并设置输出图片的最小尺寸。小于最小尺寸的图片会直接复制，不进行缩放。工具还支持批量设置精灵的 `pixelPerUnit` 属性。

### 使用方法

1. **打开工具：**  
   在 Unity 编辑器菜单栏选择 `Tools > Batch Resize and Save Images`。

2. **配置参数：**  
   - **源文件夹：** 输入包含图片的绝对路径。
   - **目标文件夹：** 输入保存缩放后图片的 Assets 路径。
   - **缩放百分比：** 设置图片缩放比例（默认 50%）。
   - **最小尺寸：** 小于该尺寸的图片不会缩放，直接复制。

3. **开始处理：**  
   点击 `Start Processing` 按钮，批量缩放并保存图片。

4. **批量设置 pixelPerUnit：**  
   点击 `Batch Set pixelPerUnit` 按钮，为所有缩放后的图片设置精灵像素单位。

5. **结果查看：**  
   缩放后的图片会保存到目标文件夹，文件名会加上 `_scaled` 后缀。  
   处理完成后会在控制台输出提示信息。

**注意：**  
该工具仅支持 PNG 和 JPG 格式图片。

## 2. 文件夹的 Bundle 设置与展示

**FolderBundleEditorWindow** 是一个 Unity 编辑器工具，用于管理项目中各文件夹的 AssetBundle 设置。它提供树形视图界面，方便查看、编辑和应用文件夹的 AssetBundle 名称，也可以一键清除所有 Bundle 设置。

### 使用方法

1. **打开工具：**  
   在 Unity 编辑器菜单栏选择 `Build > AssetBundle > Folder AssetBundle Settings`。

2. **主界面：**  
   - 窗口会以树形结构展示 Assets 下所有文件夹。
   - 列内容包括：  
     - 文件夹名称  
     - 是否已分配 Bundle  
     - Bundle 名称（可编辑）  
     - 继承的 Bundle 名称

3. **编辑 Bundle 名称：**  
   - 点击 Bundle 名称单元格可编辑或分配 Bundle 名称。
   - 子文件夹可继承父文件夹的 Bundle 名称（如未单独设置）。

4. **应用设置：**  
   - 点击 **Apply Setting** 按钮保存所有更改，并更新项目中的 AssetBundle 名称。

5. **清除设置：**  
   - 点击红色 **Clear Setting** 按钮，移除所有文件夹的 AssetBundle 名称。
   - 清除前会弹出确认对话框。

6. **其他功能：**  
   - 应用或清除设置后，工具会自动刷新树形视图。
   - 项目中未使用的 AssetBundle 名称会被移除。

**注意：**  
该工具仅影响 Assets 目录下的文件夹，仅在 Unity 编辑器环境下使用，不能在构建版本中运行。

## 3. 文件夹的 Addressable Group 设置与展示

**FolderAddressableGroupEditorWindow** 是一个 Unity 编辑器工具，用于管理项目中文件夹的 Addressable Group 设置。它提供树形视图界面，方便查看、分配和应用文件夹的 Addressable Group，有助于大型项目的资源分组和批量管理。

### 使用方法

1. **打开工具：**  
   在 Unity 编辑器菜单栏选择 `Build > Addressable > Folder Addressable Settings`。

2. **主界面：**  
   - 窗口会以树形结构展示 Assets 下所有文件夹。
   - 列内容包括：  
     - 文件夹名称  
     - 是否已分配 Addressable Group  
     - Group 名称（下拉可选）  
     - 继承的 Group 名称

3. **编辑 Group 名称：**  
   - 点击 Group 名称单元格可选择或分配 Addressable Group。
   - 子文件夹可继承父文件夹的 Group 名称（如未单独设置）。

4. **应用设置：**  
   - 点击 **Apply Setting** 按钮保存所有更改，并更新项目中的 Addressable Group 分配。

5. **清除设置：**  
   - 点击红色 **Clear Setting** 按钮，移除所有文件夹的 Addressable Group 分配。

6. **其他功能：**  
   - 应用或清除设置后，工具会自动刷新树形视图。
   - 每次操作后会保存更改并刷新 AssetDatabase。

**注意：**  
该工具仅影响 Assets 目录下的文件夹，且需要安装 Addressable Asset System 包，仅在 Unity 编辑器环境下使用，不能在构建版本中运行。
