#  Assets Management Tools

## 1. Resize Texture Batchly

**TextureBatchResizer** is a Unity Editor tool for batch resizing and saving images. It allows you to select a source folder, set a target folder, specify a scale percentage, and set a minimum size for output images. Images smaller than the minimum size will be copied directly without resizing. The tool also supports batch setting of `pixelPerUnit` for sprites.

### Usage

1. **Open the Tool:**  
   In Unity Editor, go to `Tools > UFlow > Batch Resize and Save Images`.

2. **Configure Settings:**  
   - **Source Folder:** Enter the absolute path of the folder containing your images.
   - **Target Folder:** Enter the path under Assets where resized images will be saved.
   - **Scale Percent:** Set the percentage to scale images (default is 50%).
   - **Minimum Size:** Images smaller than this size will not be resized.

3. **Start Processing:**  
   Click `Start Processing` to batch resize and save images.

4. **Batch Set pixelPerUnit:**  
   Click `Batch Set pixelPerUnit` to set the `spritePixelsPerUnit` property for all resized images.

5. **Result:**  
   Resized images will be saved in the target folder, with `_scaled` appended to their filenames.  
   The tool will log completion messages in the Console.

**Note:**  
This tool only supports PNG and JPG formats.

## 2. Show and Set Bundle Of Floder

**FolderBundleEditorWindow** is a Unity Editor tool for managing AssetBundle settings for folders within your project. It provides a tree view interface to easily view, edit, and apply AssetBundle names to folders under the Assets directory. You can also clear all bundle settings with a single click.

### Usage Guide

1. **Open the Tool:**  
   In Unity Editor, go to the menu: `Build > AssetBundle > Folder AssetBundle Settings`.

2. **Main Interface:**  
   - The window displays a tree view of all folders under Assets.
   - Columns show:  
     - Folder name  
     - Whether the folder has a bundle assigned  
     - The bundle name (editable)  
     - The inherited bundle name

3. **Editing Bundle Names:**  
   - Click on the bundle name cell to edit or assign a bundle name to a folder.
   - Bundle names can be inherited by child folders if not explicitly set.

4. **Apply Settings:**  
   - Click the **Apply Setting** button to save all changes and update AssetBundle names in the project.

5. **Clear Settings:**  
   - Click the **Clear Setting** button (red) to remove all AssetBundle names from folders.
   - A confirmation dialog will appear before clearing.

6. **Other Features:**  
   - The tool automatically refreshes the tree view after applying or clearing settings.
   - Unused AssetBundle names are removed from the project after changes.

**Note:**  
This tool only affects folders under the Assets directory. It is intended for use in the Unity Editor and does not run in builds.

## 3. Show and Set Addressable Group Of Floder

**FolderAddressableGroupEditorWindow** is a Unity Editor tool for managing Addressable Asset Groups for folders in your project. It provides a tree view interface to easily view, assign, and apply Addressable Groups to folders under the Assets directory. This helps organize and batch manage Addressable settings for large projects.

### Usage Guide

1. **Open the Tool:**  
   In Unity Editor, go to the menu: `Build > Addressable > Folder Addressable Settings`.

2. **Main Interface:**  
   - The window displays a tree view of all folders under Assets.
   - Columns show:  
     - Folder name  
     - Whether the folder has an Addressable Group assigned  
     - The group name (editable via dropdown)  
     - The inherited group name

3. **Editing Group Names:**  
   - Click on the group name cell to select or assign an Addressable Group to a folder.
   - Group names can be inherited by child folders if not explicitly set.

4. **Apply Settings:**  
   - Click the **Apply Setting** button to save all changes and update Addressable Group assignments in the project.

5. **Clear Settings:**  
   - Click the **Clear Setting** button (red) to remove all Addressable Group assignments from folders.

6. **Other Features:**  
   - The tool automatically refreshes the tree view after applying or clearing settings.
   - Changes are saved and the AssetDatabase is refreshed after each operation.

**Note:**  
This tool only affects folders under the Assets directory and requires the Addressable Asset System package. It is intended for use in the Unity Editor and does not run in builds.
