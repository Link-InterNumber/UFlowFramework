# Network Communication Tools

**UFlow** provides a simple set of network communication tools that support efficient communication between client and server. Below are the main features and usage instructions:

## Features

- **TcpGameServer**: TCP-based game server supporting multiple client connections and message handling.
- **NetClientManager**: Client manager supporting message sending, receiving, and automatic reconnection.
- **NetworkSerializer**: Provides message serialization and deserialization, supporting Protobuf format.
- **MessageReceiveHandler**: Message receive handler supporting message listening and queue processing.

---

## Usage

### 1. Start the Server

On the server side, use `TcpGameServer` to start a TCP server listening on a port.

```csharp
var server = new TcpGameServer(IPAddress.Any, 6000);
server.OnConnectedEvent += () => Debug.Log("Client connected");
server.OnDisconnectedEvent += () => Debug.Log("Client disconnected");
server.Start();
```

### 2. Client Connection

On the client side, use `NetClientManager` to connect to the server.

```csharp
NetClientManager.instance.Connect();
```

### 3. Message Sending

The client can send messages to the server via `NetClientManager`.

```csharp
var playerMove = new PlayerMove { X = 1, Y = 2, Z = 3 };
NetClientManager.instance.Send(playerMove);
```

### 4. Message Receiving

The client can listen for messages returned from the server.

```csharp
NetClientManager.instance.AddMessageListener<ServerResponse>(response =>
{
    Debug.Log($"Received response: {response.Success}");
});
```

### 5. Message Queue Processing

Supports sending and receiving messages via queues.

```csharp
var handler = NetClientManager.instance.SendQueue<ServerResponse, PlayerMove>(playerMove);
handler.AddListener(response =>
{
    Debug.Log($"Queue response: {response.Success}");
});
```

---

### Notes

- Ensure that the message types on the server and client are consistent.
- Use `NetworkSerializer` for message serialization and deserialization.
- Automatic reconnection is supported when the client disconnects.
