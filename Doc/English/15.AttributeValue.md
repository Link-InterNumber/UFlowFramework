# ✨ Flexible Attribute Tool

## 🌟 Features

1. **Flexibility**: Supports multiple data types (such as `int`, `float`, `Vector2`, `Vector3`, etc.) implemented with generics.  
2. **Extensibility**: Supports custom calculation logic by inserting expressions via `AttributeAction`.  
3. **Event-driven**: Supports listening for value change events to react to property changes.  
4. **Priority management**: Manage execution order of expressions via `AttributePriority`.  
5. **Easy integration**: Seamlessly integrates with Unity and supports serialization.

## 🛠 Capabilities

- **Value management**: Get current value, origin value, and reset values.  
- **Expression insertion**: Insert calculation logic with tags and priority.  
- **Event listening**: Subscribe to and trigger value-change events.  
- **Cloning & comparison**: Support cloning and comparing attribute values.  
- **Extension methods**: Convenient extensions (e.g., vector normalization, magnitude, etc.).

## 📖 Usage

### 1. Create attribute values

```csharp
var attributeInt = new AttributeInt(10);
var attributeFloat = new AttributeFloat(5.5f);
```

### 2. Listen for value changes

```csharp
attributeFloat.onValueChange += (current, origin, prev) =>
{
    Debug.Log($"The origin value = {origin}");
    Debug.Log($"Value changed from {prev} to {current}");
};
```

### 3. Insert expressions

```csharp
// Insert with priority
attributeInt.Push((current, origin) => current * 2, AttributePriority.Second, "MultiplyDouble");
// Default priority is AttributePriority.First
attributeInt.Push("AddFive", (current, origin) => current + 5);
Debug.Log(attributeInt.GetCurrent()); 
// The result will compute "AddFive" first, then "MultiplyDouble"
// Result is 16

attributeFloat.Push("Multiply", (current, origin) => current * 2f);
attributeFloat.Push("Add5%BasedOrigin", (current, origin) => current + origin * 0.05f);
// Pushing only marks the data as needing refresh; calculations run when GetCurrent() is called.
// If you have value-change listeners and want to trigger them now, call Calculate() to force an update.
attributeFloat.Calculate();
// Console output becomes:
//          The origin value = 5.5
//          Value changed from 5.5 to 11.275
```

### 4. Remove expressions

You can remove inserted expressions in several ways:

1. Remove by tag

```csharp
attributeInt.Remove("AddFive");
```

2. Remove by specific action

```csharp
var action = attributeInt.Push(CalculateFun);

// elsewhere
attributeInt.Remove(action);

// You can also remove by passing the function; this will remove all expressions that use that function
attributeInt.Remove(CalculateFun);
```

3. Remove the last expression

```csharp
attributeInt.Pop();
```

4. Clear all expressions

```csharp
attributeInt.ResetAction();
```

### 5. Get attribute values

```csharp
int currentInt = attributeInt.GetCurrent();
float currentFloat = attributeFloat.GetCurrent();
```

### 6. Reset attribute value

```csharp
attributeInt.Reset(20);
```

### 7. Use extension methods

```csharp
var vector3 = new AttributeVector3(new Vector3(1, 2, 3));
var normalized = vector3.Normalize();
float magnitude = vector3.Magnitude();
```

### 8. Extend with custom attributes

You can extend custom attribute types by inheriting `AttributeValue<T>`. Example creating `AttributeBool`:

```csharp
using System;

namespace PowerCellStudio
{
    [Serializable]
    public class AttributeBool : AttributeValue<bool>
    {
        public AttributeBool(bool initValue) : base(initValue) { }

        public static implicit operator bool(AttributeBool i)
        {
            return i.GetCurrent();
        }
    }
}
```

Then use it like other attributes:

```csharp
var attributeBool = new AttributeBool(true);
attributeBool.Push("Invert", (current, origin) => !current);
Debug.Log(attributeBool.GetCurrent()); // outputs false
```

## ⚠ Notes

1. **Serialization**: Ensure attribute classes and related containers support Unity’s serialization.  
2. **Event subscriptions**: Avoid memory leaks from event subscriptions; unsubscribe when appropriate.  
3. **Expression order**: Pay attention to priority when inserting expressions to avoid logic conflicts.  
4. **Type safety**: Use correct types and conversions to avoid errors from implicit casts.

## 🚀 Example

```csharp
var attribute = new AttributeFloat(10.0f);
attribute.onValueChange += (current, origin, prev) =>
{
    Debug.Log($"Value changed from {prev} to {current}");
};
attribute.Push("AddTen", (current, origin) => current + 10);
Debug.Log(attribute.GetCurrent()); 
// First logs: Value changed from 10.0 to 20.0
// Then logs: 20.0
```
