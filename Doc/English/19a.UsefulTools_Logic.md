# 🚀 Logic Utility Tools

## 1. Randomizer

`Randomizer` is a utility class for random number generation, providing various methods for generating random numbers and selecting random elements, suitable for different scenarios.

- **SetSeed**: Set the random seed.
- **Value01**: Get a random float in the range [0, 1).
- **Range**: Get a random integer or float within a specified range.
- **RandomLong**: Generate a random `long` value.
- **True**: Return a boolean value based on probability.
- **RandomSelection**: Randomly select an element from a list or array.
- **WeightedRandomSelection**: Randomly select an element from a list or dictionary based on weight.
- **RandomSelectionWithoutDuplicates**: Randomly select a specified number of elements from a list or array without duplicates.
- **WeightedRandomSelectionWithoutDuplicates**: Randomly select a specified number of elements from a dictionary based on weight, without duplicates.

### Usage

#### Basic Random Number Generation

```csharp
Randomizer.SetSeed(42); // Set random seed
float randomValue = Randomizer.Value01(); // Get a random value in [0, 1)
int randomInt = Randomizer.Range(1, 10); // Get a random integer in [1, 10)
long randomLong = Randomizer.RandomLong(); // Get a random long value
```

#### Random Selection

```csharp
var elements = new[] { "A", "B", "C" };
string randomElement = Randomizer.RandomSelection(elements); // Randomly select an element
```

#### Weighted Random Selection

```csharp
var items = new Dictionary<string, int> { { "A", 10 }, { "B", 20 }, { "C", 30 } };
string weightedElement = Randomizer.WeightedRandomSelection(items); // Randomly select an element based on weight
```

#### Non-repeating Random Selection

```csharp
var list = new List<int> { 1, 2, 3, 4, 5 };
var uniqueSelection = Randomizer.RandomSelectionWithoutDuplicates(list, 3); // Randomly select 3 non-repeating elements
```

#### Weighted Non-repeating Random Selection

```csharp
var weightedItems = new Dictionary<string, int> { { "A", 10 }, { "B", 20 }, { "C", 30 } };
var uniqueWeightedSelection = Randomizer.WeightedRandomSelectionWithoutDuplicates(weightedItems, 2); // Randomly select 2 non-repeating elements based on weight
```

## 2. Pathfinding Tools

### AStar

`AStar` is a pathfinding tool based on the A* algorithm, supporting grid map path search. It provides the following features:

- **Path**: Calculate the path from start to end.
- **SetGround**: Set the walkable area of the map.
- **Hex Grid Support**: Can switch to hex grid mode.

#### Usage

1. Create an `AStar` instance and set the walkable area of the map.
2. Call the `Path` method to calculate the path.

```csharp
var astar = new AStar();
astar.SetGround(grounds, Vector2Int.one);
List<Vector2Int> path = astar.Path(startPos, endPos);
```

---

### JPS

`JPS` is a pathfinding tool based on the Jump Point Search (JPS) algorithm, suitable for fast path search on large grid maps. It provides the following features:

- **GetPath**: Calculate the path from start to end.
- **initMap**: Initialize the walkable area of the map.

#### Usage

1. Create a `JPS` instance and initialize the walkable area of the map.
2. Call the `GetPath` method to calculate the path.

```csharp
var jps = new JPS();
jps.initMap(grounds);
List<Point> path = jps.GetPath(startPos, endPos);
```

## 3. RVO Obstacle Avoidance Algorithm

`RVO` is an obstacle avoidance tool based on the Reciprocal Velocity Obstacles (RVO) algorithm, suitable for dynamic collision avoidance in multi-agent scenarios. It provides the following features:

- **Multi-agent avoidance**: Supports collision avoidance for multiple agents in dynamic environments.
- **Static obstacle support**: Agents adjust their paths according to static obstacles.
- **Efficient neighbor query**: Accelerates neighbor detection using KdTree.
- **Multithreading support**: Optional multithreaded implementation for improved efficiency in large-scale scenarios.

### Usage

#### Initialize Simulator

1. Create a `Simulator` instance.
2. Set default agent properties.
3. Add agents and obstacles.

```csharp
var simulator = new RVO.Simulator();
simulator.setAgentDefaults(15.0f, 10, 5.0f, 5.0f, 1.5f, 2.0f, Vector3.zero);

int agentId = simulator.addAgent(new Vector3(0, 0, 0));
simulator.addObstacle(new List<Vector3> { new Vector3(1, 0, 1), new Vector3(1, 0, -1) });
simulator.processObstacles();
```

#### Run Simulation

1. Set the agent's target velocity.
2. Call the `doStep` method to execute a simulation step.

```csharp
simulator.setAgentPrefVelocity(agentId, new Vector3(1, 0, 0));
float time = simulator.doStep();
```

#### Get Agent State

Get the agent's state using the following methods:

- **Position**: `getAgentPosition(agentId)`
- **Velocity**: `getAgentVelocity(agentId)`

```csharp
Vector3 position = simulator.getAgentPosition(agentId);
Vector3 velocity = simulator.getAgentVelocity(agentId);
```
