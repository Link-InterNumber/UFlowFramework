# Visual Effects

## 1. Shake Utility Class

ShakeUtils is a lightweight shaking utility class used to create shake effects on a Transform (or a camera's Transform) in position and/or rotation. It uses coroutines for frame-by-frame processing, and only one active shake handle is kept for each target Transform. New shake requests will cancel and replace the previous one.

### API Overview (Key Symbols)
1. Class: ShakeUtils
2. Enums:
   - ShakeType (Flags): None, Position, Rotation (can be combined)
   - ShakePreset: Small, Medium, Large
3. Main Methods:
   - Shake(ShakeType shakeType, Transform target, float duration, float frequency, Vector3 magnitude, bool isUnscaleTime = true, AnimationCurve curve = null)
     Start a shake with specified parameters, returns a ShakeHandle (returns null if target is null).
   - ShakeByPreset(Transform target, ShakePreset preset, float scale = 1f, ShakeType shakeType = Position|Rotation, float duration = 0.5f, bool isUnscaleTime = true, AnimationCurve curve = null)
     Quickly start a shake using preset strength.
   - ShakeCamera(Camera camera, float duration, float frequency, Vector2 magnitude, ShakeType shakeType = Position|Rotation, bool isUnscaleTime = true, AnimationCurve curve = null)
     Shake the camera (internally calls Shake on camera.transform).
   - ShakeCameraByPreset(...) — Use preset shake for the camera.
4. Note: The implementation uses ApplicationManager.RunCoroutine to start coroutines. Your project must have this method or an equivalent coroutine starter.

### Quick Examples

1. Medium shake (position + rotation) on any object:
```csharp
using PowerCellStudio;

void DoShake(Transform target) {
    var handle = ShakeUtils.ShakeByPreset(target, ShakePreset.Medium);
    // Optional: Save handle for canceling or querying
}
```

2. Shake with custom parameters (more flexible):
```csharp
var magnitude = new Vector3(0.2f, 0.2f, 0.2f);
float duration = 0.8f;
float frequency = 25f;
var handle = ShakeUtils.Shake(ShakeUtils.ShakeType.Position, someTransform, duration, frequency, magnitude);
```

3. Small shake for the camera:
```csharp
var cam = Camera.main;
ShakeUtils.ShakeCameraByPreset(cam, ShakePreset.Small, scale: 1f);
```

4. Use a custom AnimationCurve (control attenuation curve):
```csharp
AnimationCurve curve = AnimationCurve.EaseInOut(0, 1, 1, 0); // Example: linear attenuation
ShakeUtils.ShakeByPreset(playerTransform, ShakePreset.Large, scale: 1f, duration: 0.6f, isUnscaleTime: true, curve: curve);
```
