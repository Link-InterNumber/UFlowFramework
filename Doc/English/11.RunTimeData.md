# Runtime Data Management Utility Class 🚀

## Introduction 📖

This runtime data management utility set provides an efficient and flexible way to manage runtime data in a game. By using generics and delegates, it supports multiple data storage forms (such as single-value containers and dictionary containers) and offers the ability to listen for data changes, making it easy for developers to trigger logic when data is updated.

## ✨ Features

1. Multiple storage forms:
   - Single-value container (`RuntimeData<T>`)
   - Dictionary container (`RuntimeDataDic<K, T>`)

2. Data change listening:
   - Supports listening for data changes via delegates for immediate response.

3. Modular design:
   - Separation of data storage and management logic for easier extension and maintenance.

4. Support for persistence across game restarts:
   - Offers two storage options: normal storage and storage that is not cleared on game restart.

5. Easy to extend:
   - New data types can be easily added via inheritance and generics.

## 🔧 Capabilities

- Add, get, replace, and remove runtime data.
- Support for listening to data changes.
- Provide dictionary-style data storage with key-based operations.

## 🛠️ Usage

### 1. Initialize the Runtime Data Manager

The `RuntimeDataManager` initialization method is automatically called when the game starts.

Note that `RuntimeDataManager` contains a partial method `InitRuntimeData`, which is intended for creating data when `EventManager.instance.onStartGame` fires.
How to use:
  - Create a script in your project called "RuntimeDataManager_InitRuntimeData.cs";
  - Implement the `InitRuntimeData` method in the new script.

```csharp
namespace PowerCellStudio
{
    public sealed partial class RuntimeDataManager
    {
        InitBag()
        {
            if(GetRuntimeData<BagData>() != null) return;
            var bagData = new BagData();
            bagData.AddListener(OnItemChange);
            AddRuntimeData(bagData);
        }

        ...

        partial void InitRuntimeData()
        {
            // Initialize some runtime data
            InitBag();
            ...
        }
    }
    
}
```

You can also add data elsewhere using the approach below.

### 2. ➕ Add runtime data

Add runtime data with `AddRuntimeData`:

```csharp
var bagData = new RuntimeDataManager.BagData();
RuntimeDataManager.instance.AddRuntimeData(bagData);
```

### 3. 🔍 Get runtime data

Get runtime data via the generic method `GetRuntimeData<T>`:

```csharp
var bag = RuntimeDataManager.instance.GetRuntimeData<RuntimeDataManager.BagData>();
```

### 4. 👜 Example using `BagUtils`

### Data structure setup

```csharp
namespace PowerCellStudio
{
   // Define the item data structure; it needs id and quantity fields
   public struct RItem: ICloneT<RItem>
   {
      public int id;
      public int num;

      // Implement Clone method
      public RItem Clone()
      {
         return new RItem()
         {
            id = this.id,
            num = this.num
         };
      }
   }

   // RuntimeDataManager is a partial class; you can place this code in a separate file for organization
   public partial class RuntimeDataManager
   {
      // Declare bag data using a dictionary-style RuntimeData where the item id is the key
      private sealed class BagData : RuntimeDataDic<int, RItem> { }

      // Method to initialize the bag
      public void InitBag()
      {
         if(GetRuntimeData<BagData>() != null) return;
         var bagData = new BagData();

         // Example: register an event for bag item updates.
         bagData.AddListener(OnItemChange);

         // Add the bag data into the RuntimeDataManager.
         AddRuntimeData(bagData);
      }

      // The two methods below show how to add/modify data in the bag
      
      public void AddItem(RItem rItem)
      {
         if (rItem == null) return;
         // Get the bag data
         var bag = GetRuntimeData<BagData>();
         // Find existing count by item id in the container
         var currentNum = bag?.GetData(rItem.id)?.num ?? 0;
         // Update item quantity
         rItem.num = currentNum + rItem.num;
         // Use ReplaceData() to replace the existing data
         bag?.ReplaceData(rItem.id, rItem);
      }

      public void RemoveItem(RItem rItem)
      {
         if (rItem == null) return;
         var bag = GetRuntimeData<BagData>();
         var current = bag?.GetData(rItem.id);
         if (current == null) return;
         current.num -= rItem.num;
         current.num = Math.Max(0, current.num);
         bag.ReplaceData(rItem.id, current);

         // Remove from container when quantity reaches 0
         if (current.num == 0)
               bag?.Remove(rItem.id);
      }

      public int GetItemNumber(int id)
      {
         var bag = GetRuntimeData<BagData>();
         return bag?.GetData(id)?.num ?? 0;
      }

      // How external code adds listeners to bag data
      // Must obtain the data container via GetRuntimeData<T>()
      public void AddBagListener(OnRuntimeDataChange<RItem> action)
      {
         GetRuntimeData<BagData>()?.AddListener(action);
      }
      
      public void RemoveBagListener(OnRuntimeDataChange<RItem> action)
      {
         GetRuntimeData<BagData>()?.RemoveListener(action);
      }
      
      public List<RItem> GetAllItems()
      {
         var bag = GetRuntimeData<BagData>();
         return bag?.ToList() ?? new List<RItem>();
      }

      private void OnItemChange(RItem oldData, RItem newData)
      {
         ModuleLog<BagUtils>.Log($"item id = {newData.id}, item number = {newData.num}.");
      }
   }
}
```

#### ➕ Add items

```csharp
BagUtils.AddItem(new RItem { id = 1, num = 10 });
BagUtils.AddItem(2, 5); // Add item with id 2, quantity 5
```

#### ➖ Remove items

```csharp
BagUtils.RemoveItem(new RItem { id = 1, num = 5 });
BagUtils.RemoveItem(2, 3); // Remove 3 of item id 2
```

#### 📦 Get item count

```csharp
int itemNum = BagUtils.GetItemNum(1); // Get count of item id 1
```

#### ✅ Check if item is sufficient

```csharp
bool isEnough = BagUtils.IsItemEnough(1, 10); // Check whether item id 1 has at least 10 units
```

#### 🔔 Add listener

```csharp
BagUtils.AddBagListener((oldItem, newItem) =>
{
    Console.WriteLine($"Item changed: id={newItem.id}, qty={newItem.num}");
});
```

### 5. 👂 Listen to data changes

Listen for data changes using `AddListener`:

```csharp
var bag = RuntimeDataManager.instance.GetRuntimeData<RuntimeDataManager.BagData>();
bag?.AddListener((oldItem, newItem) =>
{
    Console.WriteLine($"Item changed: id={newItem.id}, qty={newItem.num}");
});
```

### 6. 🧹 Clear runtime data

Call `ClearRuntimeData` when the game is reset to clear runtime data:

```csharp
RuntimeDataManager.instance.ClearRuntimeData();
```

## ⚠️ Notes

1. Data type requirements:
   - Data types must implement the `ICloneT<T>` interface to support cloning.
   - Key types for dictionary data must satisfy dictionary key requirements (e.g., implement `GetHashCode` and `Equals`).

2. Listener management:
   - When adding listeners, ensure they are removed at the appropriate time to avoid memory leaks.

3. Choosing storage:
   - Normal storage is cleared on game restart.
   - Use the `doNotClear` parameter to store data in storage that won't be cleared.

4. Thread safety:
   - The current implementation does not consider thread safety. If used in a multithreaded environment, add synchronization mechanisms as needed.
