# Quick Start

## 1. Import the Framework

Copy the framework folder into the `Assets` directory of your Unity project.

## 2. Configure `Addressable` and `Localization` Plugins

Addressable configuration reference: [https://docs.unity3d.com/Packages/com.unity.addressables@1.19/manual/index.html](https://docs.unity3d.com/Packages/com.unity.addressables@1.19/manual/index.html)

Localization configuration reference: [https://docs.unity3d.com/Packages/com.unity.localization@1.0/manual/index.html](https://docs.unity3d.com/Packages/com.unity.localization@1.0/manual/index.html)

Check if the `Window > Asset Management > Addressables` menu exists.
![](../img/checkAddressable.png)

Confirm the `Window > Asset Management > Localization Tables` configuration panel.
![](../img/checkLocalization.png)

## 3. Configure `ConstSetting`

Select `Tools > Editor Setting Window` to open the *Editor Setting Window*, and choose the *Const Setting* option to configure `ConstSetting`.

![](../img/constSettingWindow.png)

Note:
- The **LocalizationStringTable** option’s localized string table settings need to be consistent with the *Localization Tables* configuration.
- The **LocalizationAssetTable** option’s localized asset table settings need to be consistent with the *Localization Tables* configuration.

## 4. Set Up Entrance Scene

The framework is equipped with a preset for the entrance scene:
Select the file in the project [****/UFlowFramework/MainPreset/MainPreset.unitypackage](../../MainPreset/MainPreset.unitypackage) and click to import the prefab.

Drag the `Main.prefab` into the scene, then you can start writing the entrance script.

## 5. Write Entrance Script

Create a new script (e.g., `TestMain`) that inherits from `SceneMainBase`, and implement the `ReadyForStart()` method. When `ReadyForStart()` is called, the system has already initialized the resource system, module hub, configuration table tool, and multilingual functionality. From there, start the game process by calling the necessary logic according to the needs of your project. Below is an example:

```csharp
using PowerCellStudio

namespace YourNameSpace
{
    public class TestMain : SceneMainBase
    {
        protected override void Awake()
        {
            // Execute necessary logic before initialization
            // do something
            base.Awake();
        }

        protected void ReadyForStart()
        {
            // Execute needed logic after initialization
            // do something

            // Create a new Page container
            UIManager.instance.PushPage<LoginPage>();
            // Open the login interface
            UIManager.instance.OpenWindow<LoginWindow>();
        }
    }
}
```

Then create a new gameObject in the scene and add the `TestMain` component to the gameObject, completing the initialization of the framework functionality.

You can implement the game start logic within the `TestMain` script or use other scripts to call the `UIManager` to open different pages and windows.
