# Debug Tools

## 1. TestAttributeInspector

`TestAttributeInspector` is a custom Unity Inspector extension tool that supports the following features:

- **Test Button**: Automatically generates buttons via the `TestButtonAttribute`, which call the corresponding method when clicked.
- **Test Slider**: Automatically generates sliders via the `TestSliderAttribute`, which call the corresponding method and pass the slider value when adjusted.

### Usage

1. Add the `[TestButton]` or `[TestSlider]` attribute to the methods you want to test.
2. View the generated buttons or sliders in the Unity Inspector panel.
3. Click the button or adjust the slider to trigger the method.

#### Example Code

```csharp
using UnityEngine;
using PowerCellStudio;

public class TestExample : MonoBehaviour
{
    [TestButton("Click Me")]
    private void TestButtonMethod()
    {
        Debug.Log("Button clicked!");
    }

    [TestSlider(0, 100, 50)]
    private void TestSliderMethod(float value)
    {
        Debug.Log($"Slider value: {value}");
    }
}
```

## 2. SpaceAfterAttribute

`SpaceAfterAttribute` is a custom attribute used to add extra spacing below a field in the Unity Inspector panel.

### Usage

1. Add the `[SpaceAfter]` attribute to a field and specify the spacing height.
2. The specified spacing will appear below the field in the Unity Inspector panel.

#### Example Code

```csharp
using UnityEngine;
using PowerCellStudio;

public class SpaceExample : MonoBehaviour
{
    [SpaceAfter(20)]
    public int exampleField;
}
```

## 3. link.xml File Generation Tool

The `link.xml` file is used to configure IL2CPP linker behavior in Unity, ensuring that unused code is not incorrectly stripped during builds.

Open the tool window via `Tools > Editor Setting Window` and select `link.xml Tool`.

![Strip Link Config Editor](../img/ScriptLinkConfigEditor.png "Strip Link Config Editor")

The project uses the `LinkXmlGenerator` tool to automatically generate the `link.xml` file, supporting the following features:

- **Auto Generation**: Automatically generates the `link.xml` file based on assemblies in the project.
- **Custom Configuration**: Supports custom retention of assemblies.
- **Read Configuration**: Reads previously configured retained assemblies from the config file.
- **Visualization**: Collects used assemblies in the project and displays them in the Unity Editor.

## 4. Logger Script Auto Generation

UFlow provides a tool for automatically generating custom Logger scripts. Open the tool window via `Tools > Editor Setting Window` and select `LoggerSetting` to open the configuration.

You can customize the current Logger type or generate new Logger types.

The generated logger class format is as follows:

```csharp
// Class name generation rule: $"{LogType}Logger"
public static class ModuleLogger
{
    public static void Log(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableLog) return;
        Debug.Log($"[<color=#FF00DFFF>Module Log</color>] {message}");
    }

    public static void LogWarning(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableWarning) return;
        Debug.LogWarning($"[<color=#FF00DFFF>Module Warning</color>] {message}");
    }

    public static void LogError(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableError) return;
        Debug.LogError($"[<color=#FF00DFFF>Module Error</color>] {message}");
    }

    public static Exception Exception(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableError) return null;
        return new Exception($"[<color=#FF00DFFF>Module Exception</color>] {message}");
    }

    // If GenericArgument is checked, generic methods will also be generated
    public static void Log<T>(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableLog) return;
        Debug.Log($"[<color=#FF00DFFF>Module Log</color>:{typeof(T).Name}] {message}");
    }

    public static void LogWarning<T>(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableWarning) return;
        Debug.LogWarning($"[<color=#FF00DFFF>Module Warning</color>:{typeof(T).Name}] {message}");
    }

    public static void LogError<T>(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableError) return;
        Debug.LogError($"[<color=#FF00DFFF>Module Error</color>:{typeof(T).Name}] {message}");
    }

    public static Exception Exception<T>(object message)
    {
        if(Application.isPlaying && !ApplicationManager.enableError) return null;
        return new Exception($"[<color=#FF00DFFF>Module Exception</color>:{typeof(T).Name}] {message}");
    }
}
```
